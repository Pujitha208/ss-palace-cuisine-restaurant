# 🍽️ DineHub – Modern Restaurant Website

## Overview

DineHub is a modern, responsive restaurant website designed to provide customers with an engaging dining experience online. It features an attractive homepage, menu showcase, chef section, gallery, customer reviews, and a contact section.

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Beautiful hero section
- Interactive food menu
- About restaurant section
- Chef/team showcase
- Customer testimonials
- Contact information
- Smooth scrolling navigation
- Modern UI with animations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Design
